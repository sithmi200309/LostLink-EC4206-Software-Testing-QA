# LostLink — University Lost and Found Management System

## About the Project

LostLink is a web application designed to help university students report lost and found items through a centralized platform.

The goal is to make it easier for students to find their missing belongings and report items they have found on campus.

## Technologies Used

- MongoDB
- Express.js
- React
- Node.js

## Main Features

- Report lost items
- Report found items
- Browse lost and found reports
- Search and filter items
- View item details
- Create, read, update, and delete item reports
