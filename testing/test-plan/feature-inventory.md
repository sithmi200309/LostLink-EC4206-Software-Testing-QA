
# LostLink Feature Inventory

## 1. Project Overview

**Project Name:** LostLink

**Project Type:** University Lost and Found Management System

**Purpose:** To allow users to report, browse and manage lost and found items and communicate with item reporters.

## 2. Identified Application Features

| No. | Feature | Description | User |
|---|---|---|---|
| 1 | User Registration | Allows new users to create accounts | Visitor |
| 2 | User Login | Allows registered users to access the system | Registered User |
| 3 | User Logout | Allows users to end their sessions | Registered User |
| 4 | Browse Items | Displays reported lost and found items | All Users |
| 5 | Search Items | Allows users to search for items | All Users |
| 6 | Filter Items | Filters items using available criteria | All Users |
| 7 | Sort Items | Sorts displayed items | All Users |
| 8 | Report Item | Allows users to submit lost/found item reports | Registered User |
| 9 | View Item Details | Displays detailed information about an item | All Users |
| 10 | Edit Item | Allows users to update their own reports | Item Owner |
| 11 | Delete Item | Allows users to delete their own reports | Item Owner |
| 12 | My Reports | Displays reports submitted by the logged-in user | Registered User |
| 13 | Contact Requests | Allows users to contact item reporters and view requests | Registered User |

## 3. Identified User Roles

1. Unauthenticated Visitor
2. Registered User
3. Item Owner

## 4. Testing Scope – Initial Proposal

The above features will be considered for functional testing.

Detailed test cases and testing techniques will be prepared after analysing the individual features and their expected behaviour.

## 5. Notes

This inventory is an initial list based on the application structure and observed functionality. Feature behaviour and access restrictions must be verified during test execution.
